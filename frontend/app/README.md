# Nexus Enterprise OS - HTML CSS JS Separated

Each feature is separated into its own folder with:

- `index.html`
- `styles.css`
- `script.js`
- `screen.png`

CSS is connected in HTML using `<link rel="stylesheet" href="./styles.css">`.
JavaScript is connected in HTML using `<script src="./script.js"></script>`.

There are no internal `<style>` blocks, inline `<script>` blocks, inline `style` attributes, or inline `onclick` handlers in feature HTML files.
